# CodeCraft

Лёгкая учебная платформа для изучения HTML/CSS, JavaScript и Python. Проект рассчитан на запуск с телефона и не требует сборки.

## Запуск в TrebEdit на Android
1. Скачай ZIP-архив репозитория через **Code → Download ZIP** на GitHub.
2. Распакуй архив в файловом менеджере.
3. В TrebEdit открой папку проекта и файл `index.html`.
4. Запусти Preview. Если встроенный Preview ограничивает работу iframe, открой проект через локальный веб-сервер/предпросмотр TrebEdit, который обслуживает файлы по HTTP.

Не удаляй `sandbox.html`: он нужен для работы JavaScript-песочницы.

## Структура
- `index.html` — основная страница.
- `css/style.css` — адаптивный дизайн.
- `js/lessons.js` — учебные материалы.
- `js/app.js` — логика уроков, прогресса, теста и редактора.
- `sandbox.html` — отдельный sandbox-документ для выполнения пользовательского JavaScript.

## Возможности
- Адаптивный интерфейс для телефонов, планшетов и больших экранов.
- 6 начальных уроков по HTML/CSS, JavaScript и Python.
- Сохранение прогресса в localStorage браузера с проверкой и очисткой повреждённых данных.
- JavaScript-песочница в iframe с атрибутом `sandbox="allow-scripts"` без `allow-same-origin`.
- CSP песочницы запрещает сетевые подключения и загрузку внешних ресурсов.
- Мини-тест по HTML.
- Нет внешних библиотек, шрифтов или сетевых зависимостей.

## Ограничения
- Песочница отделяет пользовательский код от DOM и хранилища основной страницы, но не является профессиональной серверной средой исполнения недоверенного кода.
- Ограничение времени выполнения перезапускает iframe, если браузер продолжает обслуживать таймер родительской страницы. Поведение бесконечных циклов зависит от браузера и требует проверки на целевом устройстве.
- Урок Python показывает синтаксис, но не включает Python-интерпретатор в браузере.
- Физическое тестирование на Android/TrebEdit ещё требуется.

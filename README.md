# CodeCraft

Лёгкая учебная платформа для изучения HTML/CSS, JavaScript и Python. Проект рассчитан на запуск с телефона и не требует сборки.

## Запуск в TrebEdit на Android
1. Скачай ZIP-архив нужной ветки через **Code → Download ZIP** на GitHub.
2. Распакуй архив и открой папку проекта в TrebEdit.
3. Запусти `index.html` через Preview. Для iframe-песочницы и предпросмотра проектов предпочтителен локальный HTTP Preview.

Не удаляй `sandbox.html`: он нужен для JavaScript-песочницы.

## Структура
- `index.html` — основная страница.
- `css/style.css` — адаптивные стили.
- `js/lessons.js` — каталог из 32 уроков и проверочные вопросы.
- `js/app.js` — логика обучения, прогресса, редакторов, проектов и экзаменов.
- `sandbox.html` — отдельная среда запуска JavaScript.

## Возможности
- 32 урока: 16 по HTML/CSS, 8 по JavaScript и 8 по Python — от начального уровня до следующей ступени.
- В каждом уроке есть вопрос, проверка ответа и объяснение.
- Прогресс обучения, выполненные мини-проекты, закладки и заметки сохраняются локально.
- JavaScript-песочница работает в iframe с `sandbox="allow-scripts"` без `allow-same-origin`.
- Мастерская содержит три проекта: карточка профиля, мини-портфолио и страница продукта. У каждого проекта есть автоматическая проверка критериев; за первое успешное прохождение начисляется 50 XP.
- Проекты получают отметку о выполнении только после успешной проверки всех критериев; проверка анализирует HTML/CSS-код и не запускает его.
- HTML/CSS-предпросмотр запускается в iframe с пустым атрибутом sandbox: скрипты и формы отключены, CSP блокирует сетевые подключения.
- Не требуется сборка и установка пакетов; Skulpt подключается с CDN только при открытии Python-тренажёра.

## Ограничения
- Проектный предпросмотр рассчитан на HTML/CSS; JavaScript в нём намеренно отключён.
- JavaScript-песочница изолирует код от страницы, но не является профессиональным серверным исполнителем недоверенного кода.
- Python запускается через Skulpt в отдельном sandbox iframe; это не полный CPython, и первая загрузка требует интернета.
- Требуется дальнейшее тестирование на разных Android-браузерах и в TrebEdit.


## Прогресс и адаптивность
- Опыт начисляется автоматически: 20 XP за завершённый урок и 50 XP за мини-проект.
- Уровни и шесть достижений рассчитываются из уже сохранённого прогресса; отдельные данные XP не хранятся.
- Интерфейс адаптируется к широким мониторам, ноутбукам, планшетам и узким телефонам.
- Добавлена ссылка быстрого перехода к содержимому, заметный клавиатурный фокус и увеличенные сенсорные зоны.
- Для проверки на ПК удобно уменьшать ширину окна браузера: сетки и меню перестраиваются без горизонтальной прокрутки.


## Практическая лаборатория
- Десять практических заданий по HTML, CSS, JavaScript и Python с автоматической проверкой структуры и ключевых конструкций.
- Решение проверяется статически: пользовательский код не исполняется проверяющим механизмом.
- За впервые решённое задание начисляется 30 XP; результаты сохраняются в localStorage.
- Подсказки, повторное редактирование и отображение каждого критерия проверки.

## Веб-лаборатория
- Отдельные редакторы HTML, CSS и JavaScript с запуском полноценной страницы.
- Предпросмотр работает в iframe с `sandbox="allow-scripts"` без `allow-same-origin`.
- CSP запрещает сетевые запросы, внешние ресурсы, формы и базовый URL; разрешены только встроенные стили и скрипты.
- Это учебная изоляция в браузере, а не серверная среда для запуска произвольного недоверенного кода.

## Учебная система — расширение
- Каталог расширен до 32 уроков: по 8 тем для HTML/CSS, JavaScript и Python.
- Поиск по названию и содержанию уроков, фильтр по направлению.
- Экзамены можно проходить по отдельным направлениям (HTML/CSS, JavaScript, Python) или в смешанном режиме, с фильтром по уровню «Начальный» / «Начальный+». Количество вопросов зависит от выбранного набора (до 10).\n- Лучший процент, последний результат и число попыток сохраняются отдельно для каждой комбинации направления и уровня в localStorage; экзамены не начисляют XP.
- Экспорт и импорт JSON-резервной копии: прогресс, проекты, задания, закладки, заметки, черновики и историю экзаменов. Импорт объединяет данные и не стирает локальный прогресс.
- Личный учебный кабинет показывает XP, завершённые уроки, избранное и заметки; из списка можно вернуться прямо к нужному уроку.
- В каждом уроке есть кнопка добавления в избранное и поле личной заметки с автоматическим сохранением.
- Автосохранение черновиков редакторов, практических заданий и проектов в локальном хранилище браузера.
- Практическая лаборатория расширена заданиями по Python, семантическому HTML, CSS Grid и массивам JavaScript.

## Python-тренажёр
- Реальное выполнение учебного Python-кода в браузере через Skulpt 1.2.0 (MIT), загружаемый по требованию из jsDelivr.
- Ядро и стандартная библиотека загружаются только в отдельном iframe с `sandbox="allow-scripts"`, без `allow-same-origin`.
- CSP разрешает загрузку только зафиксированной версии скриптов с jsDelivr и запрещает сетевые запросы из учебной программы.
- Включён режим Python 3, ограничение выполнения — 3 секунды; есть примеры, обработка ошибок и автосохранение черновиков.
- Skulpt реализует учебное подмножество Python (ориентир — Python 3.7), а не полный CPython; поддержка сторонних библиотек и интерактивного `input()` ограничена. Для первой загрузки нужен интернет.
- Документация: [Skulpt](https://skulpt.org/using.html). CDN: [jsDelivr, версия 1.2.0](https://cdn.jsdelivr.net/npm/skulpt@1.2.0/).

## Установка и офлайн-режим
- CodeCraft можно установить как веб-приложение на поддерживаемом мобильном браузере через меню браузера «Установить приложение» / «Добавить на главный экран».
- Service Worker кэширует оболочку сайта, уроки, стили, редакторы и локальные песочницы; основные разделы остаются доступны без сети после первого успешного открытия.
- Python-интерпретатор загружается с CDN отдельно и для запуска требует интернет-соединения (его файлы не включены в офлайн-кэш).
- Service Worker работает на HTTPS или localhost; в файловом Preview TrebEdit офлайн-кэширование может быть недоступно.


## Разбор экзаменационных ошибок
- После завершения экзамена показываются вопросы, на которые дан неверный ответ, правильные варианты и пояснения.
- Можно запустить отдельную повторную попытку только по ошибочным вопросам.
- Если все ответы верны, показывается сообщение об успешном прохождении без списка ошибок.
- Повтор ошибок сохраняется как новая попытка того же набора экзамена; повторное прохождение не начисляет XP.

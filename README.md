# CodeCraft

Лёгкая учебная платформа для изучения HTML/CSS, JavaScript и Python. Проект рассчитан на запуск с телефона и не требует сборки.

## Запуск в TrebEdit на Android
1. Скачай ZIP-архив нужной ветки через **Code → Download ZIP** на GitHub.
2. Распакуй архив и открой папку проекта в TrebEdit.
3. Запусти `index.html` через Preview. Для iframe-песочницы и предпросмотра проектов предпочтителен локальный HTTP Preview.

Не удаляй `sandbox.html`: он нужен для JavaScript-песочницы.

## Структура
- `index.html` — основная страница.
- `css/style.css` — адаптивные стили.
- `js/lessons.js` — каталог из 44 уроков и проверочные вопросы.
- `js/app.js` — логика обучения, прогресса, редакторов, проектов и экзаменов.
- `sandbox.html` — отдельная среда запуска JavaScript через прерываемый Web Worker.
- `python-sandbox.html` — отдельная среда Python на Skulpt 1.2.0.
- `tests/validate.mjs` — быстрые статические проверки и проверки учебных данных.
- `tests/e2e/` — браузерные сценарии Playwright и локальный тестовый HTTP-сервер.
- `playwright.config.js` — настройки Chromium E2E.
- `package.json` — инструменты разработки и тестирования; сборка приложения не нужна.
- `docs/` — технический аудит и план развития проекта.

## Возможности
- 44 урока: 20 по HTML/CSS, 12 по JavaScript и 12 по Python — от начального уровня до следующей ступени.
- В каждом уроке есть вопрос, проверка ответа и объяснение.
- Прогресс обучения, выполненные мини-проекты, закладки и заметки сохраняются локально.
- JavaScript запускается в Worker внутри iframe с `sandbox="allow-scripts"` без `allow-same-origin`; Worker можно остановить вручную или по тайм-ауту.
- Мастерская содержит шесть проектов: карточка профиля, мини-портфолио, страница продукта, доска задач, викторина и панель показателей. У каждого проекта есть автоматическая проверка критериев; за первое успешное прохождение начисляется 50 XP.
- Проекты получают отметку о выполнении только после успешной проверки всех критериев; проверка анализирует HTML/CSS-код и не запускает его.
- HTML/CSS-предпросмотр запускается в iframe с пустым атрибутом sandbox: скрипты и формы отключены, CSP блокирует сетевые подключения.
- Не требуется сборка и установка пакетов; Skulpt подключается с CDN только при открытии Python-тренажёра.

## Ограничения
- Проектный предпросмотр рассчитан на HTML/CSS; JavaScript в нём намеренно отключён.
- JavaScript-песочница использует отдельный Worker внутри iframe с непрозрачным origin, CSP блокирует сетевые подключения, а родительская страница может завершить Worker по тайм-ауту. Это учебная браузерная изоляция, а не профессиональный серверный исполнитель недоверенного кода.
- Python запускается через Skulpt в отдельном sandbox iframe; это не полный CPython, и первая загрузка требует интернета.
- Требуется дальнейшее тестирование на разных Android-браузерах и в TrebEdit.


## Прогресс и адаптивность
- Опыт начисляется автоматически: 20 XP за завершённый урок, 50 XP за мини-проект и 30 XP за впервые решённую практическую задачу.
- Уровни и восемь достижений рассчитываются из единого набора сохранённого прогресса; отдельные данные XP не хранятся.
- Интерфейс адаптируется к широким мониторам, ноутбукам, планшетам и узким телефонам.
- Добавлена ссылка быстрого перехода к содержимому, заметный клавиатурный фокус и увеличенные сенсорные зоны.
- Для проверки на ПК удобно уменьшать ширину окна браузера: сетки и меню перестраиваются без горизонтальной прокрутки.


## Практическая лаборатория
- Двадцать практических заданий по HTML, CSS, JavaScript и Python: 10 на создание кода и 10 на исправление ошибок.
- Решение проверяется статически: пользовательский код не исполняется проверяющим механизмом.
- За впервые решённое задание начисляется 30 XP; результаты сохраняются в localStorage.
- Подсказки, повторное редактирование и отображение каждого критерия проверки.

## Веб-лаборатория
- Отдельные редакторы HTML, CSS и JavaScript с запуском полноценной страницы.
- Предпросмотр работает в iframe с `sandbox="allow-scripts"` без `allow-same-origin`.
- CSP запрещает сетевые запросы, внешние ресурсы, формы и базовый URL; разрешены только встроенные стили и скрипты.
- Это учебная изоляция в браузере, а не серверная среда для запуска произвольного недоверенного кода.

## Учебная система — расширение
- Каталог расширен до 44 уроков: 20 HTML/CSS, 12 JavaScript и 12 Python; доступен уровень «Средний».
- Поиск по названию и содержанию уроков, фильтр по направлению.

- Лучший процент, последний результат и число попыток сохраняются отдельно для каждой комбинации направления и уровня в localStorage; экзамены не начисляют XP.

- В каждом уроке есть кнопка добавления в избранное и поле личной заметки с автоматическим сохранением.
- Автосохранение черновиков редакторов, практических заданий и проектов в локальном хранилище браузера.
- Практическая лаборатория расширена заданиями по Python, семантическому HTML, CSS Grid и массивам JavaScript.

## Python-тренажёр
- Реальное выполнение учебного Python-кода в браузере через Skulpt 1.2.0 (MIT), загружаемый по требованию из jsDelivr.
- Ядро и стандартная библиотека загружаются только в отдельном iframe с `sandbox="allow-scripts"`, без `allow-same-origin`.
- CSP разрешает загрузку только зафиксированной версии скриптов с jsDelivr и запрещает сетевые запросы из учебной программы.
- Включён режим Python 3 и лимит Skulpt `execLimit: 3000`; родительская страница дополнительно ждёт не более 7 секунд и перезапускает iframe при зависании. Есть ограничение размера кода/вывода, примеры, обработка ошибок, кнопка перезапуска среды и автосохранение черновиков.
- Skulpt реализует учебное подмножество Python (ориентир — Python 3.7), а не полный CPython; поддержка сторонних библиотек и интерактивного `input()` ограничена. Для первой загрузки нужен интернет.
- Документация: [Skulpt](https://skulpt.org/using.html). CDN: [jsDelivr, версия 1.2.0](https://cdn.jsdelivr.net/npm/skulpt@1.2.0/).

## Установка и офлайн-режим
- CodeCraft можно установить как веб-приложение на поддерживаемом мобильном браузере через меню браузера «Установить приложение» / «Добавить на главный экран».
- Service Worker использует версионированный shell-кэш и ограниченный runtime-кэш (до 80 ресурсов), обновляет оболочку при сетевой навигации и отдаёт сохранённый `index.html` при потере соединения.
- После первого успешного открытия основные разделы, уроки, стили и локальные песочницы доступны без сети; Python-интерпретатор требует интернет для загрузки с CDN.
- Python-интерпретатор загружается с CDN отдельно и для запуска требует интернет-соединения (его файлы не включены в офлайн-кэш).
- Service Worker работает на HTTPS или localhost; в файловом Preview TrebEdit офлайн-кэширование может быть недоступно.
- Данные хранятся локально в браузере конкретного устройства; облачной синхронизации между устройствами нет.


## Разбор экзаменационных ошибок
- После завершения экзамена показываются вопросы, на которые дан неверный ответ, правильные варианты и пояснения.
- Можно запустить отдельную повторную попытку только по ошибочным вопросам.
- Если все ответы верны, показывается сообщение об успешном прохождении без списка ошибок.
- Повтор ошибок сохраняется как новая попытка того же набора экзамена; повторное прохождение не начисляет XP.


## Мобильная веб-лаборатория
- На узких экранах HTML, CSS, JavaScript и предпросмотр переключаются отдельными вкладками, чтобы редактор не превращался в длинную колонку.
- Панель масштаба позволяет менять размер шрифта редакторов от 11 до 20 px.
- Клавиша Tab вставляет два пробела в активный редактор вместо переключения фокуса.
- Ctrl+Enter (или Cmd+Enter) запускает предпросмотр из любого редактора.
- На широком экране редакторы и предпросмотр остаются видимыми в многоколоночной компоновке.


## Аналитика знаний по темам
- Каждый ответ в экзамене учитывается отдельно: приложение сохраняет количество верных ответов и общее число попыток по восьми учебным темам HTML, CSS, JavaScript и Python.
- В экзаменационном разделе темы сортируются от самой сложной к наиболее уверенно освоенной; процент и объём выборки показаны рядом.
- Кнопка у темы запускает отдельную тренировку только по вопросам соответствующего блока.
- Статистика тем включается в экспорт и безопасно объединяется при импорте резервной копии. Данные остаются в localStorage текущего браузера.
- Процент при малом числе ответов предварительный: оценивай его вместе с количеством попыток.

## Надёжность сред выполнения — этап A1
- JavaScript выполняется в отдельном Blob Worker, созданном внутри sandboxed iframe; Worker не имеет DOM и доступа к localStorage страницы.
- CSP JavaScript-песочницы разрешает Blob Worker, но запрещает сетевые подключения (`connect-src 'none'`). Код ограничен 100 000 символами, вывод — 50 000 символами; выполнение ограничено 1,8 секунды. Есть ручная остановка, обработка ошибок Worker и перезапуск среды после тайм-аута.
- Python-код также ограничен 100 000 символами, вывод — 50 000 символами; при ошибке CDN можно повторно загрузить отдельную среду кнопкой «Перезапустить среду».
- Лимиты уменьшают риск случайной перегрузки, но не заменяют полноценный серверный sandbox. Реальные проверки в браузере Chromium и на Android запланированы в A2/A3; текущие CI-проверки проверяют структуру и синтаксис.


## Разработка и браузерные тесты (A2)
- Приложение по-прежнему запускается как статический сайт и не требует npm для обычного использования.
- Для разработки нужен Node.js 20+; браузерные тесты используют Playwright 1.56.1, axe-core Playwright 4.14.0 и Chromium.
- Установка тестовых зависимостей: `npm install`.
- Установка браузера: `npx playwright install chromium` (в Linux CI используем `npx playwright install --with-deps chromium`).
- Запуск всех проверок: `npm test`; только браузерные сценарии: `npm run test:e2e`; только быстрые статические проверки: `npm run test:static`.
- Playwright открывает сайт через локальный HTTP-сервер и проверяет уроки, сохранение прогресса, задания, проекты, веб-лабораторию, JavaScript Worker (включая бесконечный цикл и ручную остановку), Python/Skulpt, экзамен, резервные копии и ширины 320–1920 px, альбомную ориентацию, клавиатурный фокус и WCAG 2.1 A/AA. CI прогон [42256037692](https://github.com/Artem6353/CodeCraft/actions/runs/42256037692): оба job завершились успешно, 13/13 Chromium E2E тестов прошли.
- CI запускает Chromium на Ubuntu 24.04; это не заменяет ручную проверку Android-устройства, экранной клавиатуры и других браузерных движков.


## Надёжность хранения и PWA — этап A5
- Локальные данные получили версию схемы `cc_storage_schema` (текущая — 2). Миграции выполняются последовательно и нормализуют прогресс, закладки, проекты, задания, заметки, черновики, этапы проектов и экзаменационную статистику.
- Экспорт создаёт резервную копию версии 2; импорт принимает версии 1 и 2 и объединяет данные без удаления существующего прогресса.
- Импорт предварительно нормализует данные и записывает набор ключей транзакционно: при ошибке записи выполняется попытка отката; при переполнении хранилища пользователь получает понятное сообщение.
- Service Worker использует `codecraft-shell-v2` и `codecraft-runtime-v2`, удаляет устаревшие кэши и ограничивает runtime-кэш 80 ресурсами. Ошибка записи в кэш не должна блокировать сетевой ответ.
- Офлайн-режим не включает Python runtime: Skulpt по-прежнему загружается по требованию с CDN.
- Хранилище остаётся локальным для браузера. Для переноса между устройствами используй экспорт/импорт JSON; автоматической облачной синхронизации нет.
- Браузерные проверки охватывают миграцию legacy-данных, откат при quota error и открытие сохранённой оболочки после отключения сети.

## Более строгая проверка практики — этап A9
- HTML-задания проверяются через DOMParser: комментарии и текстовые имитации тегов больше не засчитываются как реальные элементы; проверяются атрибуты и текст в DOM.
- CSS-задания проверяются по разобранным CSSStyleRule/CSSMediaRule и фактическим декларациям, а не по наличию текста в комментариях.
- JavaScript-задания получают дополнительную проверку синтаксиса через компиляцию в Function без вызова и исполнения пользовательского кода.
- Проекты дополнительно проверяются на реальный заголовок h1, повторяющиеся HTML ID и наличие разбираемых CSS-правил. Существующие тематические критерии сохранены.
- Python-задания пока используют структурные проверки; полного парсера Python в приложении нет. Эти критерии не следует считать эквивалентом исполнения тестов.

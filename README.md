# CodeCraft

CodeCraft — лёгкая многостраничная академия программирования на чистых HTML, CSS и JavaScript. Интерфейс рассчитан на телефоны, планшеты и настольные экраны; сборка приложения не требуется.

## Страницы

- `index.html` — главная и навигационный центр.
- `courses/index.html` — каталог направлений.
- `courses/html-css/index.html`, `courses/javascript/index.html`, `courses/python/index.html` — отдельные страницы курсов.
- `lesson.html?id=html1` — страница отдельного урока (ID берётся из каталога `js/lessons.js`).
- `practice.html` — 20 практических задач.
- `projects.html` — шесть мини-проектов.
- `playground.html` и `python.html` — изолированные среды JavaScript и Python.
- `exam.html` — смешанный экзамен и повтор ошибок.
- `dashboard.html` — прогресс, XP, закладки, заметки и резервные копии.
- `legacy.html` — прежняя одностраничная сборка, сохранённая для совместимости и регрессионной проверки.

## Запуск локально

Нужен Node.js 20+:

```bash
node tests/e2e/server.mjs 4173
```

Открой `http://127.0.0.1:4173/`.

## Проверки

```bash
npm install
npx playwright install chromium
npm test
```

Статическая проверка валидирует каталоги уроков, задания, ссылки и критические элементы безопасности. Playwright проверяет legacy-функциональность, независимые страницы, переходы, локальное сохранение, песочницы и адаптивность.

## Сохранность данных

Учебный прогресс хранится локально в localStorage браузера. Для переноса на другое устройство используй экспорт/импорт JSON в личном кабинете. Импорт объединяет данные, а не очищает существующие записи.

## Песочницы

- JavaScript запускается в отдельном sandboxed iframe и Web Worker. Сеть изолирована CSP; есть лимит времени, размера кода и вывода.
- Python использует Skulpt 1.2.0 в отдельном sandboxed iframe. Это учебное подмножество Python, не полный CPython. Для первой загрузки интерпретатора нужен интернет.
- Предпросмотр мини-проектов работает в iframe без разрешения скриптов и сетевых запросов.

## Netlify

В корне добавлен `netlify.toml` с publish directory `.` и `_headers` с базовыми защитными заголовками. Для Git-based deployment выбери корень репозитория как base directory и `.` как publish directory. Текущий опубликованный сайт был создан через Netlify Drop, поэтому новая Git-ветка не обновляет его автоматически.

## Производительность и доступность

В runtime нет внешних UI-библиотек и загружаемых шрифтов. Стили адаптивны, навигация управляется клавиатурой, есть skip-link, focus-visible и prefers-reduced-motion.

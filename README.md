# CodeCraft

Лёгкая учебная платформа для изучения HTML/CSS, JavaScript и Python. Проект рассчитан на запуск с телефона и не требует сборки.

## Запуск в TrebEdit на Android
1. Скачай ZIP-архив нужной ветки через **Code → Download ZIP** на GitHub.
2. Распакуй архив и открой папку проекта в TrebEdit.
3. Запусти `index.html` через Preview. Для iframe-песочницы и предпросмотра проектов предпочтителен локальный HTTP Preview.

Не удаляй `sandbox.html`: он нужен для JavaScript-песочницы.

## Структура
- `index.html` — основная страница.
- `css/style.css` — адаптивные стили.
- `js/lessons.js` — 16 уроков и проверочные вопросы.
- `js/app.js` — логика обучения, прогресса, редакторов и проектов.
- `sandbox.html` — отдельная среда запуска JavaScript.

## Возможности
- 32 урока: 16 по HTML/CSS, 8 по JavaScript и 8 по Python — от начального уровня до следующей ступени.
- В каждом уроке есть вопрос, проверка ответа и объяснение.
- Прогресс обучения и выполненные мини-проекты сохраняются локально.
- JavaScript-песочница работает в iframe с `sandbox="allow-scripts"` без `allow-same-origin`.
- Мастерская содержит три проекта: карточка профиля, мини-портфолио и страница продукта.
- HTML/CSS-предпросмотр запускается в iframe с пустым атрибутом sandbox: скрипты и формы отключены, CSP блокирует сетевые подключения.
- Нет внешних библиотек и сборки.

## Ограничения
- Проектный предпросмотр рассчитан на HTML/CSS; JavaScript в нём намеренно отключён.
- JavaScript-песочница изолирует код от страницы, но не является профессиональным серверным исполнителем недоверенного кода.
- Python пока представлен уроками, браузерного интерпретатора нет.
- Требуется дальнейшее тестирование на разных Android-браузерах и в TrebEdit.


## Прогресс и адаптивность
- Опыт начисляется автоматически: 20 XP за завершённый урок и 50 XP за мини-проект.
- Уровни и шесть достижений рассчитываются из уже сохранённого прогресса; отдельные данные XP не хранятся.
- Интерфейс адаптируется к широким мониторам, ноутбукам, планшетам и узким телефонам.
- Добавлена ссылка быстрого перехода к содержимому, заметный клавиатурный фокус и увеличенные сенсорные зоны.
- Для проверки на ПК удобно уменьшать ширину окна браузера: сетки и меню перестраиваются без горизонтальной прокрутки.


## Практическая лаборатория
- Десять практических заданий по HTML, CSS, JavaScript и Python с автоматической проверкой структуры и ключевых конструкций.
- Решение проверяется статически: пользовательский код не исполняется проверяющим механизмом.
- За впервые решённое задание начисляется 30 XP; результаты сохраняются в localStorage.
- Подсказки, повторное редактирование и отображение каждого критерия проверки.

## Веб-лаборатория
- Отдельные редакторы HTML, CSS и JavaScript с запуском полноценной страницы.
- Предпросмотр работает в iframe с `sandbox="allow-scripts"` без `allow-same-origin`.
- CSP запрещает сетевые запросы, внешние ресурсы, формы и базовый URL; разрешены только встроенные стили и скрипты.
- Это учебная изоляция в браузере, а не серверная среда для запуска произвольного недоверенного кода.

## Учебная система — расширение
- Каталог расширен до 32 уроков: по 8 тем для HTML/CSS, JavaScript и Python.
- Поиск по названию и содержанию уроков, фильтр по направлению.
- Экзамен формирует до 10 случайных вопросов из банка уроков и показывает результат.
- Экспорт и импорт JSON-резервной копии: прогресс, проекты, задания и черновики. Импорт объединяет данные и не стирает локальный прогресс.
- Автосохранение черновиков редакторов, практических заданий и проектов в локальном хранилище браузера.
- Практическая лаборатория расширена заданиями по Python, семантическому HTML, CSS Grid и массивам JavaScript.

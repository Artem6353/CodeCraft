# CodeCraft

Лёгкая учебная платформа для изучения HTML/CSS, JavaScript и Python. Проект рассчитан на запуск с телефона и не требует сборки.

## Запуск в TrebEdit на Android
1. Скачай ZIP-архив нужной ветки через **Code → Download ZIP** на GitHub.
2. Распакуй архив в файловом менеджере.
3. В TrebEdit открой папку проекта и файл `index.html`.
4. Запусти Preview. Если встроенный Preview ограничивает работу iframe, используй локальный HTTP Preview/сервер TrebEdit.

Не удаляй `sandbox.html`: он нужен для работы JavaScript-песочницы.

## Структура
- `index.html` — основная страница.
- `css/style.css` — адаптивный дизайн.
- `js/lessons.js` — учебные материалы и вопросы к урокам.
- `js/app.js` — логика уроков, прогресса, теста и редактора.
- `sandbox.html` — отдельный sandbox-документ для пользовательского JavaScript.

## Возможности
- Адаптивный интерфейс для телефонов, планшетов и больших экранов.
- 16 начальных уроков: HTML, CSS, JavaScript и Python.
- Проверочный вопрос с объяснением в каждом уроке.
- Сохранение прогресса в localStorage с проверкой данных.
- JavaScript-песочница в iframe с `sandbox="allow-scripts"` без `allow-same-origin`.
- CSP песочницы запрещает сетевые подключения и внешние ресурсы.
- Нет внешних библиотек, шрифтов или сетевых зависимостей.

## Ограничения и безопасность
- Песочница отделяет пользовательский код от DOM и хранилища основной страницы, но не является профессиональной серверной средой для исполнения недоверенного кода.
- Таймер перезапускает iframe по истечении 1,8 секунды; поведение бесконечных циклов зависит от браузера и требует проверки на целевом устройстве.
- Python пока представлен уроками и примерами; встроенного Python-интерпретатора нет.
- Физическое тестирование на разных Android-устройствах и браузерах требуется отдельно.
